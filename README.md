# Python Basics — 1P

A beginner-friendly Jupyter notebook for practicing Python fundamentals with automatic checks.

## Open in Google Colab

[Open `python_basics.ipynb` in Colab](https://colab.research.google.com/github/OlavStend/1P/blob/main/python_basics.ipynb)

## Contents

- Variables and strings
- Numbers and arithmetic
- Celsius-to-Fahrenheit conversion
- Conditionals
- Lists and built-in functions
- Loops
- Functions

Students can run each exercise cell and then the automatic check directly beneath it. The checks are intended for learning and feedback, not secure assessment.
